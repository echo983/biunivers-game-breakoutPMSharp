# v1 实测清单（Playtest Checklist）

> 版本：0.5.2（main 已合并）
> 目的：在 Biunivers 桌面实测 v1，收集手感数据，为参数微调与 v1.1 范围提供依据。
> 方式：逐项实测，反馈记入第 6 节。预计 20-40 分钟。

## 1. 基础流程

- [ ] 开局出现三球拍选择界面，点击与键盘 1/2/3 均可选择
- [ ] 选择后球粘在球拍上，空格/点击可发球
- [ ] 球落出底部后自动回到球拍（扣 1 球）
- [ ] 5 球耗尽出现 GameOver，点击或 R 重开（保留球拍）
- [ ] 清空全部砖块出现 Victory，点击或 R 重开

逐拍体验，各打半局：

## 3. 增压节奏

- [ ] 颠球 1-2 次：球速应明显低于 3-4 次（热身段）
- [ ] 颠球 3 次：能否够到软砖区并破软砖
- [ ] 颠球 4 次：能否破普通砖
- [ ] 颠球 5-6 次：能否破硬砖
- [ ] 颠球 7+ 次：球速是否快到明显难接（风险递增感）
- [ ] 有没有感觉「10%/速度」节奏不对的地方（太快/太慢/无法积累）

## 4. 砖块与球数

- [ ] 软砖阈值（500）：是否轻松可破
- [ ] 普通砖阈值（800）：需要颠几次才有把握
- [ ] 硬砖阈值（1100）+ 2 HP：需要几次？第一击后是否有「半血」反馈
- [ ] 5 球：够不够通关？通关时剩余几球？
- [ ] 破砖节奏：打起来爽吗？还是拖沓/太快？

## 5. 环境与边界

- [ ] 顶部滞留带（B1 风险）：有没有遇到球在砖顶与天花板之间来回弹、长时间不下来
- [ ] 球卡在某个角落/轨道超过 5 秒的情况
- [ ] 最小窗口（360×400）下：砖块、球拍、HUD 是否全部可见
- [ ] 窗口缩放过程中砖块是否跟随重排、无错位
- [ ] 碗内球始终可见（半透明生效）
- [ ] 渲染无闪烁/深度错乱/穿模
