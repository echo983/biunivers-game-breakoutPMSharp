# 物件球拍物理破坏游戏 — 设计草案 v0.1

> 归档日期：2026-08-16
> 状态：草案，参数待手感实验确定

## 1. 核心定义

这是一款以**物理碰撞、可破坏环境和不同物件球拍**为核心的单机游戏。

它继承 Breakout 的基本关系：

```
球 → 球拍 → 环境
```

但不再把「平板反射 + 清空砖块」作为完整游戏。

核心变成：

> 玩家使用具有不同几何、材料和动力学性质的现实物件控制球，在有限球数内完成关卡目标。

暂称：

**物件球拍物理破坏游戏**（Object-Paddle Physics Game）

---

## 2. 关卡基本结构

每关由四部分构成：

```
Level = (Balls, Paddle, Environment, Objective)
```

### Balls：球

玩家拥有固定数量的球，例如 `Balls = 5`。

掉出底部边界：`Balls := Balls - 1`。仍有球 → 重新发球。球耗尽且目标尚未完成 → 失败。

因此关卡不存在无限磨砖。

### Paddle：球拍物件

「球拍」不是一种固定设备，而是任意适合作为碰撞工具的物件，例如：

滑板、橄榄球、碗、腰带、鼓、木板、平底锅、盾牌、球棒、网兜。

物件差异不是皮肤，而是物理差异。定义：

```
P = (G, M, D, C)
```

- `G`：Geometry，几何形状
- `M`：Material，材料
- `D`：Mass Distribution，质量分布
- `C`：Control，玩家可以怎样控制它

---

## 3. 球拍的核心：局部法线

传统 Breakout 的挡板基本是平面，局部法线变化很小，因此通常需要人为根据碰撞位置修改球的出射角。

这里尽量不用这种隐藏规则。球的方向主要由：

```
碰撞位置 + 局部法线 + 物体运动 + 材料响应
```

共同决定。因此**形状本身就是控制器**。

例如半橄榄球形凸面：中央接触 → 接近向上反射；两侧 → 横向分量增加；接近尖端 → 极端角度。

玩家实际上是在控制：**球撞到物件的哪一块表面。**

---

## 4. 不同物件产生不同操作语言

### 滑板

长、较平、两头翘起。中部稳定，板头可以挑球，可以通过倾斜改变出射方向。

**稳定反射 + 边缘挑射型**

### 橄榄球

凸曲面，局部法线连续变化。中央稳定，两端高度敏感，能产生大角度反射。

**曲率瞄准型**

### 碗

凹曲面。球可能：进入 → 沿内壁滚动 → 改变方向 → 重新飞出。

**捕获 / 导引型**

### 鼓

存在弹性膜。撞击 → 膜面形变 → 储能 → 回弹。

**弹性储能型**

### 腰带

柔性物体，可以弯曲、甩动，而不是作为固定碰撞面。

**柔性抽击型**

---

## 5. 重力

整个场地存在恒定向下重力：`g⃗ = (0, -g)`。但 `g ≠ 必须等于 9.81 m/s²`，采用**物理规律一致、尺度参数游戏化**。

重力有三个作用：

1. 使球自然具有返回玩家区域的趋势；
2. 使低速与高速阶段自然不同（低速明显抛物线，高速轨迹接近弹丸）；
3. 使碗、鼓、腰带、掉落物、碎片共享同一个物理世界。

---

## 6. 单球增压

每当球成功被玩家控制的球拍反弹一次：

```
v_new = 1.10 × v_old
```

即速度 +10%。注意：只有球拍接球触发。撞墙、砖、天花板、普通环境不触发增速。

> **已标定（0.4.2）**：经物理仿真确定 `1.30`（+30%），并设球速上限 `2000 px/s`。
> 标定依据（球拍自动跟踪球，模拟每次接球）：
> - `1.10`：颠球 7 次后发射速度仅 628 px/s，最高 y=215，永远够不到砖块区
> - `1.30`：发射速度 650 → 798 → 947 → 1100 → 1271 → 1459 → 1684；
>   颠球 3 次首次够到砖块区，4 次破普通砖，之后风险递增直至上限
> - `1.40+`：失控过快

因此每次成功续球，本质上是：**续命一次 = 下一阶段风险增加一次**。

---

## 7. 单球生命周期

一颗球的自然过程：

```
发球（低速、容易控制）
→ 球拍回击（v × 1.1）
→ 继续破坏环境
→ 再次回击（v × 1.1）
→ 越来越高速
→ 最终：完成目标；或玩家失去控制，球掉出场地
```

所以一颗球本身就是一次有限生命周期。

---

## 8. 速度同时是风险和资源

如果高速只意味着「越来越难」，增压只是死亡计时器。所以加入：

### 速度穿透

球的穿透能力随速度增加。概念上：

```
Penetration = f(m, v, θ, Material)
```

砖块具有阻力 `Resistance = R`。撞击以后，如果 `P > R` 则打穿。剩余 `P' = P - R` 如果仍然足够 → 继续穿下一块。直到穿透能力不足，发生反弹或停止贯穿。

---

## 9. 速度阶段

球会自然经历：

- **低速**：弧线明显、容易瞄准、一般一次处理一个目标
- **中速**：传统反弹玩法、破坏能力提高
- **高速**：可以连续击穿数块、反应窗口缩短
- **极高速**：类似弹丸、贯穿能力很强、接球风险极高

因此 `速度↑ ⇒ 破坏能力↑`，同时 `速度↑ ⇒ 可控性↓`，形成 **风险 ↔ 收益**。

---

## 10. 材料系统

物体不只是形状不同。为材料定义统一参数：

```
M = (ρ, e, μ, c, k, σ)
```

密度、恢复系数、摩擦、阻尼、刚度、破坏阈值。可进一步增加塑性、撕裂、脆性等参数。

- **金属**：高刚度、高密度，容易发生高速跳弹
- **木材**：中等刚度和阻尼，可以断裂
- **陶瓷**：形变小，达到阈值后碎裂
- **塑料**：根据种类有较明显弹性和形变
- **牛皮**：柔性、高阻尼、大形变
- **布**：抗拉而几乎不抗弯，需要柔性/布料模型

---

## 11. 几何、材料、形变必须分离

建议底层结构始终保持：

- **Geometry**：形状、碰撞位置、局部法线
- **Material**：摩擦、弹性、吸能、碰撞响应
- **Deformation**：是否弯曲、凹陷、拉伸
- **Failure**：裂、碎、撕、永久变形

这样**木头碗**和**金属碗**可以共享几何，却有完全不同的行为。

---

## 12. 砖块不是游戏目标本身

正式确定：**砖块是可破坏关卡介质**，而不是「必须全部消灭」的目标。

砖阵可以承载：路径、隐藏物、拼图、门、钥匙、开关、空腔、机关、结构支撑。

玩家是在**修改关卡空间**。

---

## 13. 胜利条件

不同关卡可以使用不同 Objective，但所有目标都通过同一套物理语言完成：

- **清除型**：摧毁全部指定目标
- **挖掘型**：传送门埋在砖阵内部，玩家挖开路径 → 暴露传送门 → 把球真正射进传送门
- **收集型**：例如四个拼图碎片 `P₁+P₂+P₃+P₄ ⇒ Victory`，不要求清空全部环境
- **机关型**：击中若干目标或按某种状态激活装置

它们共享：`球 → 碰撞 → 世界状态变化 → Objective 进度`。

---

## 14. 完整核心闭环

```
发球 → 瞄准 → 破坏环境 → 推进任务 → 球回落 → 球拍接球
→ 改变轨迹 → 速度+10% → 破坏力增加 → 控制难度增加
→ （继续循环）
```

直到：

- **A**：`Objective = Complete` → 胜利
- **B**：球掉落，`Balls - 1` → 下一球
- **C**：`Balls = 0` 且目标未完成 → 失败

---

## 15. 两层有限资源

游戏实际上有两个资源：

1. **关卡资源**：剩余球数 —— 硬资源
2. **单球资源**：当前球仍然可控的剩余生命周期 —— 非显式数值，随速度增加而逐渐消耗

玩家同时面对：**要不要珍惜剩余球？** 以及 **这颗已经很危险的高速球，要不要继续利用？**

---

## 16. 必须保留的收束条件

1. **防止永久轨道**：球不能无限在无意义轨道中循环。如果较长时间没有破坏、任务推进、球拍接触，施加轻微环境扰动打破稳定循环。
2. **高速仍然必须具有技能空间**：速度可以最终失控，但不能长期进入「看不清 → 无法预测 → 纯随机」。主要速度区间中 `Skill → Outcome` 必须明显成立。
3. **穿透不能取代反射**：不能让高速最终变成「什么都无视，直线穿过去」。材料、厚度、入射角仍然有效，例如高速球 + 斜金属面仍可能跳弹而非穿透。

---

## 17. 最小可玩原型（MVP）

第一版不需要布料、碎裂等复杂系统。建议 MVP 只有：

- **球**：1 种
- **球拍**：3 种（平板/滑板、半橄榄球凸面、碗形凹面）
- **环境**：3 种砖（普通砖、软砖、高阻力砖）
- **物理**：重力、刚体、曲面碰撞、速度增压、高速穿透
- **目标**：2 种（清除指定砖；挖出并进入传送门）
- **资源**：固定球数

如果这一版已经产生「我要把球打在哪里 → 让它在上面多干活 → 回来时怎样利用球拍形状重新送上去 → 是否值得冒险维持这颗高速球」这种思考，那么核心就成立。

---

## 最终结构

整个设计可以浓缩成一句话：

> **用不同现实物件控制一个在重力场中不断增压的球，以越来越高的风险换取越来越强的环境破坏能力，并在有限球数耗尽以前完成空间型关卡目标。**

目前没有明显的结构性断点。尚未确定的主要不是「还缺什么系统」，而是几个需要原型实验的连续参数：

```
g、+10%、穿透曲线、基础球速、球数
```

这些应该通过手感实验确定，而不是继续在纸面上增加规则。
